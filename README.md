This is my Claude Slop attempt at bringing the dual screen Pokemon Ruby and Sapphire GBA pinball port to the DS.

https://github.com/jonnisvibes/jvppbport

I have been testing this, fixing visual issues and bugs over the past several days. If you notice anything unexpected let me know and I'll take a look. While this is Claude generated, I have done everything I can to ensure that it isn't "slop." There have been dozens and dozens of builds.

This was more ambitious than I realized. It was originally targeting the DSi for its faster processor. I figured it had a wider appeal targeting the DS so emulation devices could also use it. It runs at a steady 60 FPS, but just barely. I am not anticipating adding any more features because it does not take much to anger the framerate. If you encounter any choppiness or audio stuttering ensure that your handheld has sufficient power.

I have been testing this exclusively on real hardware. It should also run fine on melonDS. I have confirmed that it boots in Drastic but haven't extensively play tested it.

If you are playing on real hardware, you will need to place a copy of the GBA rom in /roms/gba or alongside the .nds file.

If you are playing on an emulator, run the included HTML file to build a standalone rom.
